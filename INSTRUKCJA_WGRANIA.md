# Anna Stefańska – poprawiona strona

W paczce znajdują się pliki witryny GitHub Pages. Przesłany tekst jest w `o-mnie.html`.

## Aktualizacja GitHub
1. Zrób kopię zapasową repozytorium GitHub przed zmianami.
2. Wgraj zawartość paczki **do katalogu głównego repozytorium**, nie sam plik ZIP i nie dodatkowy katalog `anna_stefanska_responsywna`.
3. Zachowaj ścieżki `css/style.css`, `js/script.js` i `images/logo-header.png`, `images/logo-hero.png`.
4. Jeśli w repo są dodatkowe pliki lub zmiany niewystępujące w paczce, zachowaj je.
5. Zatwierdź zmiany (**Commit changes**), sprawdź witrynę po publikacji; w razie potrzeby odśwież `Ctrl+F5`.

## Co poprawiono
- `o-mnie.html`: cały tekst „Trochę o mnie” w czytelnych sekcjach.
- Spójne menu (w tym rozwijane na telefonie) na wszystkich podstronach.
- Skalowanie logo, typografii i przycisków na małych ekranach.
- Jednokolumnowe karty i formularz na telefonach.
- Zachowane kolory i treści pozostałych podstron.

Uwaga: formularz kontaktowy w przekazanym projekcie nie miał systemu obsługi wysyłki – poprawki responsywności nie aktywują wysyłania wiadomości.
