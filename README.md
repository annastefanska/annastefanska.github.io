# Przestrzeń Czułości – strona HTML (bez CMS)

Gotowa, responsywna wersja strony dla GitHub Pages.

- Strona główna: `index.html`
- O mnie: `o-mnie.html`
- Oferta: `oferta.html`
- Biblioteka: `biblioteka.html`
- Blog: `blog.html`, `artykul-zaloba-dziecka.html`
- Sklep z przelewem: `sklep.html`
- Kontakt: `kontakt.html`

Wszystkie podstrony używają wspólnego `css/style.css` i `js/script.js`.
Nie zawiera CMS, logowania, bramki płatności ani backendu. Po zakupie
potwierdzenie wpłaty jest wysyłane przez program pocztowy klienta.

Instrukcja całkowitej wymiany zawartości repozytorium: `START_TUTAJ.md`.
